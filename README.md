# Triki Music Controller 🎵

Умное десктопное приложение для управления мультимедиа в Windows с помощью умного носимого контроллера **Triki** (BLE) и встроенной студии самообучения жестов.

## 🌟 Основные возможности

1. **Беспроводное BLE-подключение к Triki**:
   - Автоматический поиск и быстрое сопряжение с умным кольцом/шайбой Triki.
   - Мониторинг уровня заряда аккумулятора (Battery Level) в реальном времени.
   - Автоматическое переподключение при разрыве связи.

2. **🎓 Интерактивная Студия Обучения Жестов (Training Studio)**:
   - Пользователь сам записывает естественные движения под свои привычки.
   - Поддерживаемые действия:
     - ⏯ **Пауза / Плей** (по умолчанию: взмах вниз)
     - ⏭ **Вперёд / Следующий трек** (взмах вправо)
     - ⏮ **Назад / Предыдущий трек** (взмах влево)
     - 🔊 **Громче** (вращение вправо)
     - 🔉 **Тише** (вращение влево)
     - 🧘 **Покой / Шум руки** (отсечение ложных срабатываний)
   - 3-шаговый мастер записи: выбор действия, таймер обратного отсчета с динамическим прогресс-баром, сбор пиковых ускорений (G) и угловых скоростей (°/с), и моментальное обучение модели.

3. **🎮 Живое распознавание и управление**:
   - Неоновые карточки действий со световой индикацией срабатывания.
   - Управление мультимедиа-клавишами Windows (Spotify, Яндекс.Музыка, YouTube, плееры ОС).
   - Интеллектуальный фильтр удержания кнопки Triki: жесты анализируются в момент осознанного зажатия кнопки, исключая случайные срабатывания при ходьбе или жестикуляции.

4. **📊 Телеметрия датчиков в реальном времени**:
   - 6-осевой IMU: акселерометр (X, Y, Z в G) и гироскоп (X, Y, Z в °/с).
   - Индикация состояния аппаратной кнопки и заряда батареи.
   - Подробный журнал событий (Event Log) с возможностью экспорта и очистки.

5. **🌍 Трёхъязычная локализация (Multilingual RU / EN / PL)**:
   - Полная поддержка трех языков: **Русский** (🇷🇺 RU), **Английский** (🇬🇧 EN), **Польский** (🇵🇱 PL).
   - Переключение на лету прямо из шапки приложения без перезапуска.
   - Сохранение настроек языка в `%APPDATA%\TrikiMusicController\settings.json`.

6. **🪟 Фоновая работа в системном трее**:
   - Сворачивание в область уведомлений Windows (System Tray).
   - Динамические цветные иконки статуса (зеленая — подключено, желтая — поиск, красная — отключено).
   - Контекстное меню и всплывающие подсказки (Balloon Tips).

## 🛠 Требования для сборки и запуска

- **ОС**: Windows 10 (версия 19041+) или Windows 11 с поддержкой Bluetooth Low Energy (BLE).
- **SDK**: [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) или новее.
- **Среда разработки**: Visual Studio 2022 / JetBrains Rider / VS Code.

## 🚀 Сборка и запуск

Склонируйте репозиторий:
```bash
git clone https://github.com/your-username/TrikiMusicController.git
cd TrikiMusicController
```

Сборка проекта:
```bash
dotnet build
```

Запуск приложения:
```bash
dotnet run
```

Публикация автономного релиза (Self-contained single exe):
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 📂 Структура проекта

```text
TrikiMusicController/
├── App.xaml / App.xaml.cs            # Точка входа WPF приложения, загрузка локализации
├── MainWindow.xaml / .xaml.cs        # Главное окно: вкладки распознавания, студия обучения, трей
├── Loc.cs                            # Модуль мультиязычности (RU/EN/PL) и сохранение настроек
├── TrikiBleService.cs                # BLE-клиент: поиск, подключение, подписка на характеристики IMU
├── GestureLearningEngine.cs          # Движок машинного обучения и сопоставления жестов
├── GestureRecording.cs               # Модели сессий записи и калибровки
├── MusicGestureProcessor.cs          # Обработка жестов и фильтрация ложных движений
├── MediaKeyController.cs             # Эмуляция клавиш мультимедиа Windows API
├── TrikiModels.cs                    # Модели данных датчиков IMU и состояния
├── TrikiLogger.cs                    # Файловый логгер событий
├── Assets/                           # Иконки статусов приложения (.ico)
└── TrikiMusicController.csproj       # Конфигурация проекта .NET 9
```
